## Brand & Style

The brand personality centers on rigorous scientific precision, technical authority, and intuitive analytical intelligence. Designed for data scientists, academic researchers, and machine learning practitioners, the product transforms statistical complexity into decisive, validated action. The aesthetic merges **Corporate / Modern High-Tech** with **Developer-Centric Precision**—avoiding frivolous ornamentation while elevating data visualization, tabular density, and state transparency.

### Emotional Response & Aesthetic Tenets
- **Cognitive Relief & Reassurance:** Visuals reduce decision fatigue through unambiguous status semantics, deterministic path trees, and clean semantic labeling.
- **Academic & Engineering Credibility:** A balance of slate tones, deep indigo structures, and luminous cyan/teal accents projects the gravitas of a certified statistical suite.
- **Technical Rigor:** Crisp tabular metrics, dedicated monospaced code blocks, parameter chips, and calibrated badge alerts ensure zero ambiguity when reviewing assumption evaluations and model benchmarks.

## Colors

The palette is anchored by deep slate backgrounds that isolate eye fatigue during extensive analytical workflows, contrasted against a high-contrast spectrum of luminous accents.

### Palette Architecture
- **Primary (`#6366F1` - Electric Indigo):** Anchors primary decision pathways, interactive flow nodes, selected tabs, and affirmative recommendations.
- **Secondary (`#0D9488` - Deep Precision Teal):** Governs algorithmic confirmations, verified assumptions, and mathematical significance highlights.
- **Tertiary (`#F59E0B` - Amber Alert):** Dedicated to statistical anomalies, assumption violations requiring non-parametric rerouting, and boundary warnings (e.g., p-hacking alerts, severe class imbalance).
- **Neutral (`#0F172A` - Deep Obsidian Slate):** Acts as the foundational structural base, paired with interior surface tiers (`#1E293B` and `#334155`) to establish hierarchy without stark contrast spikes.

### Semantic Status Palette
- **Normal / Parametric Pass (`#10B981`):** Applied to validated assumptions (e.g., Shapiro-Wilk $p \ge 0.05$, homoscedasticity confirmed).
- **Violation / Non-Parametric Trigger (`#EF4444` / `#F59E0B`):** Indicates rejected null distributions, triggering non-parametric fallback switches.
- **Diagnostic Info (`#38BDF8`):** Highlights interpretive insights, confidence intervals, and context tooltips.

## Typography

The type system blends structural geometric precision with readability:

- **Headlines (Space Grotesk):** Provides technological personality, clear mathematical balance, and authoritative structure to system summaries and major module dividers.
- **Body & Interpretations (Inter):** Serves analytical cards and automated narrative translations ("İnsan Dilinde Sonuçlar") with maximum optical clarity across long sessions.
- **Data, Formulas & Code (JetBrains Mono):** Drives statistical indicators ($p$-values, degrees of freedom, sample sizes), Python/R snippets, matrix outputs, and metric comparison chips. Monospaced tabular alignment prevents jitter during dynamic recalculations.

## Layout & Spacing

The layout is built upon a **12-column fluid grid system** anchored within a maximum width of `1440px`. The analytical workspace optimizes high information density without visual crowding.

### Grid & Breakpoints
- **Desktop (1024px+):** 12 columns with 20px (`1.25rem`) gutters and 32px (`2rem`) margins. Permits multi-panel views: Decision Flow Wizard (4 cols), Live Diagnostic Engine (8 cols), or split Model Evaluation matrices (6 cols + 6 cols).
- **Tablet (768px – 1023px):** 8 columns with 16px (`1rem`) gutters. Side-by-side metric tiles collapse into vertically stacked cards; decision trees shift into progressive accordions.
- **Mobile (< 768px):** 4 columns with 12px (`0.75rem`) gutters and 16px (`1rem`) margins. Navigation shifts to a sticky top stepper; comparison matrices convert to horizontal swipeable panels.

### Rhythm Principles
- Component interior spacing relies on a strict `8px` geometric sub-grid (`space-xs` = 4px, `space-sm` = 8px, `space-md` = 16px, `space-lg` = 24px, `space-xl` = 40px).
- Metric cards must consistently maintain `space-md` internal padding, expanding to `space-lg` for interactive code synthesis boards.

## Elevation & Depth

Depth is articulated through **tonal surface tiering** combined with subtle, high-blur ambient shadows and **low-contrast precision outlines**.

### Surface Tiers
1. **Canvas (Base Level):** `#0F172A` — Deep foundation for full application viewports.
2. **Surface Tier 1 (Analytical Cards & Panels):** `#1E293B` with a `1px` crisp border in `rgba(71, 85, 105, 0.4)`.
3. **Surface Tier 2 (Interactive Floating Modules, Code Boxes & Modals):** `#334155` with `1px` border in `rgba(99, 102, 241, 0.25)`.
4. **Code Recessed Surface:** `#090D16` with an inner border of `rgba(255, 255, 255, 0.05)` to create terminal-like inset contrast.

### Shadows
- **Level 1 (Cards, Tables):** `0 4px 12px -2px rgba(0, 0, 0, 0.35)`
- **Level 2 (Popovers, Decision Nodes, Dropdowns):** `0 10px 24px -4px rgba(0, 0, 0, 0.45), 0 0 0 1px rgba(99, 102, 241, 0.15)`
- **Level 3 (Modal Dialogues, Code Fullscreen Overlays):** `0 24px 48px -12px rgba(0, 0, 0, 0.65), 0 0 16px rgba(20, 184, 166, 0.1)`

## Shapes

The design system employs a **Soft (Level 1)** geometric profile. Modest corner radii complement the mathematical, laboratory-grade software character, preventing the interface from appearing overly casual or gamified.

- **Standard Elements (Buttons, Inputs, Metric Badges):** `4px` (`0.25rem`) radius.
- **Containers & Data Cards:** `8px` (`0.5rem`) radius (`rounded-lg`).
- **Modal Overlays & Multi-panel Boards:** `12px` (`0.75rem`) radius (`rounded-xl`).
- **Status Indicators & Node Connectors:** Hard circular indicators (`50%`) are used strictly for status state dots and interactive flow connectors.

## Components

### Buttons
- **Primary Action (e.g., "Analizi Başlat", "Kodu Kopyala"):** Solid `#6366F1` background, `#FFFFFF` text, `4px` radius, hover state illuminated with a `rgba(99, 102, 241, 0.25)` glow, active state scaled to `0.98`.
- **Secondary Action (e.g., "Parametreleri Değiştir"):** Transparent background with `1px` solid `#475569` border, hover background transition to `rgba(51, 65, 85, 0.5)`.
- **Ghost / Utility:** Borderless, muted typography (`#94A3B8`), hover state reveals light background fill.

### Metric Badges & Status Chips
- **Assumption Status Chips:** Composed of a `20px` height container featuring a `6px` status dot.
  - Normal/Accepted: `bg-emerald-950/40 text-emerald-300 border border-emerald-500/30`.
  - Violated/Non-Parametric: `bg-rose-950/40 text-rose-300 border border-rose-500/30`.
  - Ambiguous/Check: `bg-amber-950/40 text-amber-300 border border-amber-500/30`.
- **P-Value Indicators:** Strict `JetBrains Mono` font with color-coded significance brackets ($p < 0.05$, $p < 0.01$, $p < 0.001$).

### Interactive Decision Tree Elements
- **Node Cards:** Structured blocks containing parameter checks (e.g., "Grup Sayısı $\ge 3$"). Features connector anchors (`border-indigo-500/50`) that highlight active paths dynamically.
- **Reroute Bridges:** High-visibility banner modules communicating fallback transitions (e.g., strikethrough `ANOVA` $\rightarrow$ vibrant badge `Kruskal-Wallis`) with explanation tooltips.

### Code Synthesis Block
- Monospaced editor frame (`#090D16`), dark slate title bar displaying target runtime (`Python · SciPy`, `Statsmodels`, `R`), language badge, and a persistent one-click copy button with clipboard confirmation state.

### Comparative Model Evaluation Matrix
- Tabular display featuring zebra striping across dark tiers (`#1E293B` and `#162032`).
- Integrated inline bar indicators showing performance metrics (Speed, Interpretability, Accuracy) out of 100, with a pinned star badge for the algorithmically recommended balanced choice.

### Persona Expertise Toggle
- Segmented switch control with two discrete states: **Yeni Başlayan** (accessible terminology, semantic descriptions) and **Uzman** (complete statistical notation: $F, H, \eta^2, \varepsilon^2$). Smooth background slide transition between segment states.
